### What I learned

When I’m working with a mobile-first approach, I try not to depend too much on media queries if I can solve things in a simpler way.

For example, I like using properties like max-width so elements can adapt more naturally to different screen sizes without needing a lot of breakpoints. It feels easier to manage and keeps the code a bit cleaner.

I’m also paying attention to spacing (like margins and padding), since it really helps keep a good visual flow across devices, instead of fixing everything with screen-specific rules.

I’m still learning, but my idea is to first try making things responsive in a flexible way, and only use media queries when I really need them.
